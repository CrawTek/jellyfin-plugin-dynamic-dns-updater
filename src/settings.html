Dynamic DNS (DDNS) Updater Operations

The Jellyfin DDNS Updater automatically maintains your remote access connection by monitoring and updating your domain's public IP address.

Operational Logic

  • Automated Checks: The updater runs every 10 minutes. You can monitor or adjust this frequency via Dashboard → Scheduled Tasks → Dynamic DNS Updater.
  • Smart Update Throttling: To prevent unnecessary network traffic and avoid provider rate-limits, unchanged IP addresses are automatically filtered and skipped.
  • Cooldown Enforcement: Triggering a manual check via the "Check now" button respects the exact same cooldown rules as automated tasks to prevent API abuse.
  • Service Dependent: IP tracking and background updates are active only while the Jellyfin server application is running.

Security & Hardening

  • Access Control: Your provider secret keys are isolated in a dedicated configuration file, securely restricted to be readable only by the core Jellyfin operating system account.
  • Encrypted Transmission: Always use an HTTPS connection when managing your server or entering provider credentials remotely to prevent credential interception.
  • Backup Management: Treat your system backups as sensitive material. Because they mirror your live directory structure, they contain your raw DDNS authentication keys and must be heavily protected.
